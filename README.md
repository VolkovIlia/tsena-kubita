# «Цена кубита»

Интерактивная история о вычислениях: игрок — диспетчер вычислительного бюро и за одну неделю выясняет, на какие заказы стоит покупать квантовый компьютер. Четыре исполнителя — Мастер (одно ядро), Бригада (64 ядра), Фабрика (видеокарта) и Оракул (будущий квантовый компьютер) — соревнуются в одной валюте: «тиках», элементарных операциях.

- Концепт: `docs/concept.md` · ревью: `docs/review.md` · план: `docs/roadmap.md`
- Сценарий: `story/05_draft/` (пролог, главы 1–6, финал; ~30 минут)
- Числа: `data/params.json` → `src/model/tick.ts` → `npm test`
- Источники и векторы поиска: `research/`
- Правила для агента: `CLAUDE.md`

```bash
npm install
npm test
```
