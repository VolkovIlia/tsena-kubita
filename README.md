# Цена кубита

Интерактивная хроника о вычислениях: от статьи Шеннона до обещаний 2029 года игрок выясняет, где квантовый компьютер быстрее обычного, а где нет. Четыре машины — одно ядро, 64 ядра, видеокарта и будущий квантовый компьютер с исправлением ошибок — соревнуются в одной валюте: «тиках», элементарных операциях.

- Концепт: `docs/concept.md` · ревью: `docs/review.md` · план: `docs/roadmap.md`
- Сценарий: `story/05_draft/` (пролог «Новости», главы 1–9, финал; ~45–50 минут)
- Числа: `data/params.json` → `src/model/tick.ts` → `npm test`
- Источники и векторы поиска: `research/`
- Правила для агента: `CLAUDE.md`

```bash
npm install
npm run dev     # локальный сервер Vite
npm test        # модель чисел, форматирование, словарь, прогресс
npm run check   # svelte-check: типы и доступность
npm run build   # статический сайт в dist/
```

Играбельны все 11 колод: пролог (`#prologue`), главы `#chapter-1` … `#chapter-9` и финал (`#finale`).
