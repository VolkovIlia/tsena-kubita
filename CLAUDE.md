# CLAUDE.md — «Цена кубита»

Интерактивная научпоп-история (формат The Evolution of Trust) о том, где квантовый компьютер выигрывает у CPU/GPU, а где нет. Язык продукта — русский (английская локаль — позже). Статус на 25.10.2026: концепт и сценарий утверждены, модель чисел и тесты готовы; Этап 0 и вертикальный срез (пролог, гл. 3–4) реализованы.

Главная мысль, которую игрок уносит: **квантовый компьютер быстрее не во всём — он быстрее в другом.** Правило: мало данных на входе, мало на выходе, экспоненциальная структура внутри.

## Жёсткие правила

1. **Числа — только из модели.** Любое число в репликах и на экранах берётся из `src/model/tick.ts`, который читает `data/params.json`. Никаких чисел, вписанных в UI руками. Новое число → поле в `params.json` с `source`, `source_url`, `verified` → тест в `tick.test.ts`.
2. **`npm test` всегда зелёный.** Если правка ломает тест — значит, меняется число в сценарии. Обнови `story/05_draft/*` и `docs/` в том же коммите и напиши, почему число изменилось.
3. **Ни одного утверждения без источника.** Факт о квантовых вычислениях в тексте или сноске → строка в `research/sources.md`. Источник, который ты не открыл сам, помечай `⚠ не проверено`. Никогда не выдумывай ссылки, DOI, номера arXiv и цитаты.
4. **Первоисточник важнее пересказа.** Порядок доверия: статья (arXiv / журнал) → блог лаборатории-автора → научная журналистика (Quanta, IEEE Spectrum, Nature News) → всё остальное. Пресс-релизы о «превосходстве» проверяй по классическим опровержениям.
5. **Не создавать новых мифов.** Ни «кванты решат всё», ни «кванты бесполезны». Любой новый экран проверь по `story/01_style/taboo_list.md`.
6. **Оракул — будущая машина** с исправлением ошибок (параметры Хёфлера). Сегодняшние чипы в тексте — «его младшие братья». Не смешивать.
7. **Стиль и голоса** — `story/01_style/` и `story/03_characters/`. Экран: одна мысль, ≤ 3 строк; реплика ≤ 20 слов; «разбор» ≤ 35 слов; обращение на «ты».
8. **Действие раньше объяснения.** Каждая глава: заказ → ставка → гонка → разбор → правило в блокнот. Вывод никогда не показывается до ставки игрока.

## Как искать контекст

Начинай с `research/vectors.md`: там для каждой главы готовые запросы (RU/EN), что именно найти и чем проверить. Найденное — в `research/sources.md` (одна строка: что, ссылка, для какой главы, статус). Если источник меняет число или вывод — сначала `research/open-questions.md`, решение принимает автор.

## Стек (решено)

- Vite + Svelte 5 + TypeScript, анимация на SVG/Canvas, тесты — Vitest.
- Статический сайт без бэкенда (GitHub Pages или аналог); прогресс — в `localStorage`.
- Маленький собственный симулятор вектора состояния (3–10 кубитов) для пинбола; ориентир — открытая библиотека Quantum Flytrap `quantum-tensors`.
- i18n с первого дня: все строки в словарях `src/i18n/ru.ts` (позже `en.ts`), ключи по главам.
- Версии пакетов не угадывай: ставь через `npm create vite@latest` / `npm i`, затем фиксируй в lock-файле.
