## Вердикт

Концепт научно прочен, но драматически был пуст. Три блокирующие проблемы исправлены в сценарии:

1. **Нет центрального вопроса и ставок** → хозяйка бюро Марго хочет купить Оракула на весь бюджет; у игрока неделя; финал — решение о покупке.
2. **11 механик на 30 минут** → один цикл «заказ → ставка → гонка → разбор → правило в блокнот» + три особые механики (телефонная книга, волновой пинбол, доска памяти / ритм числа).
3. **Арка Оракула шла только вниз** → Оракул недооценён, проигрывает на чужом поле (гл. 4–5) и разгромно выигрывает в гл. 6.

Ещё три серьёзные: интерференция — самое трудное место (одна точная картинка со столбиками амплитуд); ловушка «маршрут» перенесена в гл. 4 (после появления Оракула); победа кубита получила механики.

## Второстепенное

1. Финальная фраза → «Он быстрее не во всём. Он быстрее в другом».
2. Каждое большое N — с образом (номера телефонов, пароли, песчинки).
3. Денежный слой «тика» — вне v1.
4. CPU-параметры — откалибровать бенчмарком.
5. «Тик» определяется один раз Мастером в прологе.
6. Глава «Как читать новости» растворена в финале.
7. Конструктор логического кубита → 40-секундная интерлюдия в гл. 4.
8. Обращение на «ты», сухой юмор, без восторгов.

## Риски непрерывности

- Оракул = будущая машина; сегодняшние чипы — «младшие братья».
- Числа в репликах и в расчёте — из одного JSON (см. `CLAUDE.md`, правило 1).
- Вход по прямой ссылке → карточка «что ты уже знаешь».
