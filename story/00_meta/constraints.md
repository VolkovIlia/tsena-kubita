# Ограничения

- Все числа — из `../data/params.json` через модель; тесты зелёные.
- Каждое научное утверждение и каждое событие хроники — с записью в `../research/sources.md`.
- Квантовый исполнитель в гонках — будущая машина с исправлением ошибок (параметры Хёфлера). Сегодняшние чипы (Sycamore, Willow, Majorana 2) — только события хроники, по именам; в гонках не участвуют.
- Выдуманных персонажей нет. Люди — только реальные (Фейнман, Шор, Гровер, Дейкстра, Амдал, Саттер, Тан, Хёфлер, Рейхер), компании — Google, IBM, Microsoft. Цитата — только дословная, из открытого источника, со ссылкой.
- Машины называются как есть: «1 ядро», «64 ядра», «видеокарта», «квантовый компьютер». У них нет лиц, реплик и чувств.
- Не создавать обратного мифа «кванты бесполезны»: глава «Своё поле» — реальные победы.
