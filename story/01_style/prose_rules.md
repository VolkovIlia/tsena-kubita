# Правила текста

- Один слайд — одна мысль: текст рассказчика ≤ 3 строк, реплика ≤ 20 слов, «разбор» ≤ 35 слов.
- Подпись кнопки продолжает фразу («Кто тут главный?», «Дальше: вторник»).
- После ставки следующий слайд начинается с реакции на выбор игрока.
- Каждое большое число — с образом: «10 квадриллионов кодов — это все 16-значные комбинации, длиной с номер банковской карты».
- Маленькие числа раньше больших; одна новая переменная на главу.
- Термин появляется после явления и объясняется в той же фразе.
- Формулы — только в сноске «для любопытных».
- Вывод формулирует игрок (ставка, выбор); текст подтверждает.
- Юмор — из характеров, не из каламбуров.
- Время — в человеческих единицах: секунды, дни, «дольше возраста Вселенной».
