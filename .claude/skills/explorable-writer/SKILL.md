# Explorable Writer — голос «Цены кубита»

Перед работой прочитай: `story/01_style/*`, `story/03_characters/supporting_cast.md`, нужную главу в `story/05_draft/`, `story/02_story/open_loops.md`.

## Каркас любой главы

Заказ → ставка игрока → гонка → разбор → правило в блокнот. Вывод **никогда** не появляется раньше ставки. Неверная ставка не наказывается: меняется только реплика Марго.

## Жёсткие лимиты

- Экран: одна мысль, ≤ 3 строки.
- Реплика: ≤ 20 слов. Разбор: ≤ 35 слов.
- Обращение на «ты», настоящее время.
- Большое число всегда с образом из быта.
- Термин — только после того, как игрок увидел явление; объяснение в той же фразе.

## Голоса

| Персонаж | Как говорит | Пример |
| --- | --- | --- |
| Марго | Заголовки, восклицания; единственная, кому можно «!» | «Конкуренты уже купили!» |
| Мастер | Коротко, сухо, с гордостью за хитрость | «Я не быстрый. Я хитрый.» |
| Бригада | Хором, потом спорят и ждут | «Нас шестьдесят четыре! …Петров, ты закончил?» |
| Фабрика | КАПСОМ, слова через точку | «ДАЙТЕ. ОДИНАКОВЫХ. ЗАДАЧ.» |
| Оракул | Медленно, многоточия, образы волн и холода | «Я слышу, где волны сходятся.» |
| Нина | Прямо, устало, без шуток | «Мне нужно точно.» |

## Проверка перед сдачей текста

1. Нет слов из `story/01_style/taboo_list.md` (кроме мифа в устах Марго, который будет опровергнут).
2. Каждое число есть в `src/model/tick.test.ts` или `data/params.json` — иначе вызови `numbers-guard`.
3. Каждый научный факт имеет строку в `research/sources.md`.
4. Оракул нигде не выдаётся за существующую сегодня машину.
5. Шутка не объясняется; мораль не повторяется дважды.
6. Длины укладываются в лимиты — посчитай слова.

## Формат вывода

Экраны в стиле `story/05_draft`: `**Экран N.**` описание, реплики цитатой `> **Имя:** текст`, действия игрока курсивом. Для i18n — ключи `chN.screenM.speaker.k`.
